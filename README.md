# Mi proyecto
Este proyecto es una practica de Git Hub y Git
## Instalacion
Para utilizar este proyecto se necesita tener Git instalado.
## Comandos utilizados
git init: El init se usa para crear un repositorio de Git en una carpeta.
git add: El add sirve para preparar los archivos que quiero guardar en el commit.
git commit: El commit funciona para guardar los cambios en el historial del proyecto.
git push: El push sirve para subir mis cambios desde el computador a GitHub.
git status: El status sirve para revisar si tengo archivos modificados o nuevos.
git diff: El diff sirve para ver que cambios hice en un archivo antes de hacer el commit.
git log: El log es para ver el historial de commits del proyecto.
git restore: El restore sirve para quitar cambios que hice en un archivo y volver a la ultima version guardada.
